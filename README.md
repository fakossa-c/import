# Guide des bénévoles de La Remise

La Remise est un tiers-lieu associatif installé dans un ancien entrepôt : un atelier partagé, un café et une salle que l'on peut louer. Ce guide rassemble ce qu'il faut savoir pour tenir une permanence.

Il remplace le fichier Word qui circulait par e-mail. Il se lit directement sur cette page, y compris sur un téléphone.
